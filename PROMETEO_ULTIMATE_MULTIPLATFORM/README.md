# PROMETEO ULTIMATE 0.10.0-dev

Progetto Android nativo Kotlin/Jetpack Compose. Include la revisione grafica della Home e una dashboard riservata COSMO di sviluppo, oltre al flusso locale frase segreta → credenziali già presente nella 0.9.

## Apri il progetto
Aprire questa cartella in Android Studio. Requisiti: JDK 17, Android SDK 35 e Gradle compatibile con i plugin dichiarati. Istruzioni dettagliate: `docs/BUILD_ANDROID_WINDOWS.md`.

## Materiale Google AI Studio
Prompt tecnico completo: `docs/GOOGLE_AI_STUDIO_PROMPT_IT.md`. Caricare anche `docs/RIFERIMENTO_DESIGN_PROMETEO_COSMO.png` come riferimento visuale.

## Test e limiti
Consultare `docs/TEST_E_STATO_0_10.md`. Questo archivio non contiene un APK: la compilazione Android non è stata possibile nell'ambiente di preparazione. Autenticazione locale non adatta a dati reali; backend e MFA sono ancora da implementare.
